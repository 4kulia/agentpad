# Frozen chat timeline reference (W00)

W00 records the historical production renderer at source HEAD `b6a714b621fdcdefdda38052b86acfa2386e13a3` before native migration. At that commit, `ChatTimelineView` mounted a SwiftUI `ScrollView`/`LazyVStack`. W11 mounts the native AppKit table unconditionally and removes that timeline and its rows. The frozen reference preserves the old rendered behavior, including its capability gates, quirks and documented absences.

The migration specification is `docs/agentpad/CHAT-NATIVE-TIMELINE.md` in the specification checkout. Its T01–T39, S01–S26 and R01–R55 inventories are the 120 preservation boundaries. A01–A10 are future architecture gates for W01 onward. The external `test-catalog.json` retains exact inventory/acceptance text, source references, resolved existing test declarations and explicitly proposed checks. Source inspection is distinguished from execution. The adjacent `visual-state-checklist.json` enumerates visual substates; it is a requirement list, not capture evidence.

The frozen evidence package lives outside the repository. Set `AGENTPAD_CHAT_NATIVE_REFERENCE_ROOT` to its absolute directory; capture destinations must resolve beneath that root, including through symlinks. Its manifest/configuration and captures must identify source and fixture hashes, exact message IDs/revisions, fonts, theme/preset, scale, locale/timezone/fixed dates, contrast, widths and anchors. Captures must identify the actual state they show, with decoded-image settlement verified where applicable. Uncaptured states remain gaps. Reference pixels and archived reports are preserved; candidate comparison uses a separate output. Both themes at channel width 760 and thread width 420, narrow layouts and applicable resize transitions are required by the specification.

Shared event/probe logic belongs only in test support. The native adapter mounts the actual product wrapper and preserves the archived fixture/event signatures and timing boundaries. The old SwiftUI and hosted-table reference implementations are archived outside the build. There is no renderer selector or fallback in the product.

`chat-native-reference.json` is the test-only path/configuration contract. SwiftPM excludes this Fixtures directory from the test resources, and no app target consumes it. `ChatScrollMount.swift` owns the mount adapter and the one shared event/probe implementation. `ChatScrollWorkload.swift` owns the archived mixed/media sequences, sample validation and percentile calculation. The original continuity/restoration/input/media callers retain their shared mount aliases.

Run captures with `AGENTPAD_CHAT_NATIVE_REFERENCE_CAPTURE` set to a fresh absolute subdirectory of the external reference root, then invoke `python3 scripts/test-quiet.py --log-dir <external-job-log-directory> --filter ChatTimelineReferenceTests`. Never reuse a frozen capture destination. The producer writes each PNG with matching JSON metadata and a final `captures.json` index; failures preserve partial artifacts for diagnosis.

Include `ChatTimelineQuietStateTests` to exercise the real attachment Save action through an unordered `NSSavePanel` completion seam, enumerate production menus without tracking them, verify tooltip wiring, and sample accent/contrast traits on native production views. The Save tests verify cancellation, failure/retry, exact downloaded bytes and owner/rights invalidation. Scoped test-only Objective-C overrides restore their original implementations before returning. Captures include the actual fixture messages and distinguish sampled traits from live OS transitions. The production reaction picker is also captured from its quiet child popup window after pressing the real toolbar action.

System menu tracking, tooltip bubbles and Save-panel chrome remain explicit visual gaps; menu/tooltip contracts and Save routing assertions are alternative evidence, not replacement pixels. Actual OS-setting transitions and any control whose recorded `requestedControlHasLocalFocus` is false remain release-session checks. Source-only tooltip checks are identified as such. A runtime coverage ledger beside the external job report reconciles every inventory label with completed indexed captures or a named gap and alternative check. `AGENTPAD_CHAT_NATIVE_REFERENCE_VIEWPORT_ONLY=1` and `AGENTPAD_CHAT_NATIVE_REFERENCE_DRAFTS_ONLY=1` are diagnostic subsets; their partial indexes must never be accepted as the complete reference. Draft captures hold fixture requests in the real manager's transfer slots and assert waiting, uploading at 45%, and checking immediately before the bitmap, together with their visible status labels.

Run the existing opt-in producers with `AGENTPAD_ATTACHMENT_CAPTURE`, `AGENTPAD_CHAT_POLISH_CAPTURE`, `AGENTPAD_B1_CAPTURE` and `AGENTPAD_R115_CAPTURE` set to separate external directories, using the same quiet runner. Record the broader regression with `--filter Chat`. Live/keychain opt-ins must be unset for fixture runs.

After the reference package is complete, set `AGENTPAD_CHAT_NATIVE_REFERENCE_VALIDATE` to its absolute directory to enable `ChatNativeReferenceManifestTests`. Validation can read a relocated package and does not require the capture root variable. It verifies the archived source snapshot's hash, archived evidence hashes, every primary event signature, paired decodable PNGs, per-capture metadata/fixture hashes and loaded-image pixel evidence. The committed `chat-native-reference-expected.json` independently requires 1,040 captures and reconciles all 531 inventory substates, both themes and required widths with explicit gaps and nonbitmap contracts. It retains the 23 known state gaps and explicitly names the missing required widths for 40 additional states; partial-width captures do not imply complete width coverage. Removing one record or an entire theme pair fails validation. Whole-repository file hashes remain recorded provenance and are not compared with the live checkout. Unrelated source edits and intentional native renderer changes are allowed while the reference artifacts remain immutable; candidate parity runs use a separate evidence root. Archived reports referenced by the external archive manifest must remain available at their recorded locations.

All native test/capture runs use `scripts/test-quiet.py` and the project's quiet containment: nonactivating/offscreen fixture windows, direct window event delivery, muted sound and view-rendered bitmaps. A run that cannot remain quiet stops with incomplete evidence. Opt-in snapshot producers must actually execute and leave decoded captures; a skipped test or an exit code alone does not prove coverage. Capture and benchmark commands/configuration are recorded with the external run evidence. Do not rerun archived scratch reporters into their historical output paths.

Known baseline suite failures remain documented in the specification checkout's `CLAUDE.md`; they are neither silently fixed nor represented as migration passes. In particular, the open accessibility restoration and full-Chat-order media-scroll observations need separate native-path verification. Existing tests whose names contain “Native” may still exercise SwiftUI components hosted in AppKit windows.

W11 switches all four callers to native, migrates direct row fixtures to `ChatNativeRowFixture`, and retires live comparisons that require the deleted renderer. Frozen images and manifests remain external, and native behavior coverage replaces each retired legacy-only test. The owner's 2026-11-08 release decision requires the full applicable suite and one native workload run on the switch-over candidate. The primary workload remains 1,360 valid moving events, with dense-reaction and loaded-image workloads reported separately. Timings and machine load are diagnostics, with no performance threshold. The rare isolated deferred-input scroll jump is an accepted known defect and is still reported; layout errors, incorrect final positions, overlap, frequent jumps or a different jump pattern remain defects. Hardware and VoiceOver checks are performed by the owner on the test build.

The owner's 2026-10-23 Q1 decision preserves per-message native text selection; continuous selection across messages is separate scope. Q2 requires a controlled fixture session for actual hardware momentum, scroller, keyboard and VoiceOver before final release acceptance, with its evidence separate from comparable quiet measurements; that session does not block implementation.
