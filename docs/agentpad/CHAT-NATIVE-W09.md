# W09 native timeline parity contracts

The production default remains the legacy timeline. The native NSTableView is
available only through the existing internal opt-in seam; native cells contain
AppKit views. External reaction popovers may retain their existing SwiftUI hosts.

W09 capture probes in legacy views compile only with both `DEBUG` and
`AGENTPAD_CHAT_NATIVE_W09_CAPTURE`. Ordinary Debug and Release builds retain the
original layout, accessibility and observation paths. Capture tests also compare
the instrumented legacy rendering with a probe-free rendering.

The generic parity gate, frozen color environment, media continuity deadline and
0.75-point jump threshold are unchanged. The following owner decisions are narrow
exceptions, not comparator tolerance changes.

## Archived picker — 2026-10-31

After an already-open reaction picker rejects an action because the channel was
archived, native consistently disables its six quick reactions and Add. It keeps
the popup controller/window, typed input, selection and focus, displays the existing
guard error, and creates no command. Legacy's order-dependent enabled state remains
unchanged. Raw paired mismatches are retained; all pixels outside the six matching
observed quick-control drawing frames still pass the original comparison.

## Pins control evidence — 2026-11-06

For the shared All/Agents/People segmented control only, the eight
`channel-pins-panel-{1040,760,420,320}-{light,dark}` records use equal actual public
font, segment labels/count, selection and frames plus exact zero-margin control
pixel equality. Real dispatched Agents → People → All transitions must separately
prove selection and visible author filtering. Other caller assertions remain in
force; no generic glyph or comparator change is authorized.

## Twenty fractional placements — 2026-11-06

Native keeps pixel-aligned geometry. The owner accepts only the recorded 0.5-point
placement differences in these finite record sets:

- `draft-strip-{importing,live-states}-{420,320}-{light,dark}-{before,after-scroll-reload}`: sixteen records.
- `reveal-late-260-{light,dark}-{before,arrived}`: four records.

Raw paired screenshots and FAIL results are preserved with a separate decision
disposition. Fonts, colors, line breaks, actions, ownership and continuity must
still pass. Every different state, width, offset or new difference remains FAIL.

Hardware/VoiceOver acceptance, the controlled W10 benchmark and W11 switch-over
remain separate release requirements.
